# Seungwoo Noh Portfolio — implemented design system

The initial skill-generated recommendations were refined for a software engineering portfolio. DESIGN.md defines the chosen editorial direction.

- Typography: system sans-serif (Inter when already installed, then Apple/Windows system fonts); system monospace for metadata. No remote font downloads.
- Dark default: background #0b0c0e, text #f2f3f0, secondary #9da3ac, dividers #282c31.
- Light: background #fafaf8, text #151819, secondary #59616a, dividers #dedfda.
- One restrained green accent, actual product screenshots, no invented photography.
- Main width 1160px. Responsive gutters 48px desktop and 20px mobile; 8/16/24/32/48/64/104px spacing rhythm.
- 44px mobile icon controls, visible focus, reduced motion support, semantic content, native dialog for image zoom.
- Headings use negative tracking and a deliberate size hierarchy. Long technical text has a constrained reading width.
- Components: header, editorial hero, screenshot project card, focus filters, technical case study, architecture diagram, evidence cards, contextual boundaries, source links, footer.
